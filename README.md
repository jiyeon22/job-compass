# 지원용 기업 분석 워크북

기업명만 넣으면 **조사 바로가기**와 **①~⑩ 분석 양식**이 준비되는 무료 웹사이트입니다.
가입, API 키, 서버, 비용이 모두 필요 없습니다. (`index.html` 파일 하나로 동작)

## 기능
- 조사 바로가기: 회사 홈페이지·DART 공시·네이버 뉴스·사람인·잡코리아·원티드·잡플래닛·면접 후기 검색을 한 번에
- ①~⑩ 분석 양식: 한눈에 보기(추천도 %), 기본 정보, 주요 사업, 최근 동향, 인재상, 직무, 내 경험 연결표, 자소서 키워드, 면접 대비, 보완점
- 추천도: 4개 항목 슬라이더로 채점하면 원형 게이지로 자동 계산
- AI로 자동 채우기(선택): 부탁서를 복사해 ChatGPT·Gemini·Perplexity·Claude 등에 붙여넣고, 답변을 다시 붙여넣으면 양식이 채워짐
- 프로필 여러 개 저장·수정·삭제, 분석 목록 저장·삭제, 자동 저장, 리포트 마크다운 복사
- 모든 데이터는 각자 브라우저(localStorage)에만 저장

## 참고
- 데이터는 브라우저별로 따로 저장됩니다. 다른 기기에서는 보이지 않고, 브라우저의 사이트 데이터를 지우면 사라집니다. 중요한 리포트는 [리포트 복사]로 따로 보관하세요.
- 조사 바로가기는 각 사이트의 검색 결과 페이지로 연결됩니다. 사이트 구조가 바뀌면 일부 링크가 검색 첫 화면으로 열릴 수 있습니다.
